# /design.md — Site visual system template

````markdown
# <Title> — Design system

## Concept
One-line visual idea.

## Layout
Grid, max width, nav (sticky or not), footer.

## Color
Tokens (background, text, accent, muted).

## Typography
Google Fonts families only. Record the exact Google Fonts `<link>` snippet.

## Components
Nav, button, card, form, footer — states if needed.

## Motion
CSS or small JS (nav toggle). No React.

## Accessibility
Contrast, focus rings, heading order, reduced-motion.
````
